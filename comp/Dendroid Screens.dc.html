Dendroid/Notes are a graph

Notes are a graph

Your notes are one Markdown graph rather than a collection of pages. A heading is a node, and the headings beneath it are its children, so structure emerges from writing instead of from filing. You can drill into any node and treat it as the whole document.

Linking

Type @ to link any heading in the app — for example @Sync providers. Typeahead completions are ordered by distance from the current block, not alphabetically.

  • Child headings are implicit links to their parent
  • Any node in the tree can become the editor root
    • Reset returns the editor to the tree root
  • Folders, tags, notebooks

Depth

  1. Set how many descendant levels render inline
  2. Deeper headings collapse to a single line
Structure should be a consequence of thinking, not a prerequisite for it.
